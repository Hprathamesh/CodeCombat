Hero commands
hero.moveRight(n);
Walk n tiles right. Also moveLeft, moveUp, moveDown. n defaults to 1.
hero.moveXY(x, y);
Walk to a tile, going around walls.
hero.attack(enemy);
One turn: step toward the enemy, or strike if next to it (2 damage).
hero.findNearestEnemy()
Returns an Enemy*, or nullptr when none are left.
hero.findEnemies()
Returns a vector<Enemy*> of living enemies.
hero.findGems()
Returns a vector<Item*> of gems on the ground. hero.findPotions() does the same for potions.
hero.findNearest(list)
The closest thing in a vector, or nullptr when it is empty.
hero.say("text");
Show a speech bubble.
hero.x, hero.y, hero.health
Where you are and how healthy you are.
enemy->alive, enemy->health
Check on a foe. Also enemy->x, enemy->y, enemy->type. Items have x, y and type.
list.size(), list.empty()
Work with vectors. list[0] is the first entry.
cout << value << endl;
Print text to the output shown below the board.

Your code runs in a built-in C++ subset: int, bool, string, auto, vector, pointers with ->, if, for, while, functions and cout. Tiles are counted from 0 at the top left; the numbers on the board edge show x and y.
